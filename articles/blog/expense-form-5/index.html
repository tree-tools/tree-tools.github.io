GASで経費申請フォームを作ってみた（5/6）ー年月に合わせて保存先フォルダを用意するー

投稿日：2026-11-17 | カテゴリ：技術 | GASWebアプリGoogle Drive

このブログでは、Google Apps Script（GAS）で作ったツールや、作る途中で気づいたことを紹介しています。「こんな使い方もできるんだ」と、普段の作業を見直すヒントになればうれしいです。

前回は、フォームに添付されたレシート画像をGoogleドライブへ保存する仕組みを紹介しました。今回は、その保存先を購入した年月に合わせて用意する部分です。

やりたかったこと

もともとは、管理者がその都度、月ごとのレシート画像の保存先フォルダを作成していました。ただ、作業漏れなどで、新しい月のフォルダが用意されていないことがありました。

また、申請者が自分で画像をフォルダへ入れる際に、違う月のフォルダへ保存してしまうこともありました。

そこで、申請フォームに入力された購入日から保存先の年月を決め、画像を自動で振り分けるようにしました。さらに、対象の年月のフォルダが未登録なら、申請時に保存先を用意して管理表にも記録する仕組みを追加しました。

管理者が毎月フォルダを準備する負担と、申請者が保存先を選ぶ際の間違いを減らすことが目的です。

使ったロジック・ポイント

① 購入日から年月を取り出す

保存先の基準にするのは、申請した日ではなく、経費の購入日です。

例えば、9月に申請しても、購入日が8月なら「2026年08月」のフォルダを使います。月を2桁でそろえ、フォルダ名から対象の年月が分かるようにしています。

② 登録済みの保存先を先に確認する

スプレッドシートの管理表には、年・月・フォルダのリンクを記録しています。申請された経費の年月にリンクが登録されていれば、その保存先を使います。

毎回新しいフォルダを作るのではなく、管理表を確認してから保存先を決める流れです。

③ 未登録なら、親フォルダの中に用意する

管理表にリンクがない場合は、あらかじめ指定した親フォルダを確認します。親フォルダのURLも同じシートに置き、保存先に関する設定をまとめました。

親フォルダの中に対象年月のフォルダが1つ見つかれば、それを再利用します。見つからない場合に、新しいフォルダを作成します。

これにより、フォルダ自体はあるのに管理表への登録だけが抜けていた場合も、保存先を重ねて作らずに済みます。

④ 作成したリンクを管理表に残す

フォルダを用意したあとは、その年月とリンクを管理表へ記録します。年月の行がすでにあってリンクだけが空欄なら、その欄を埋めます。行がなければ、新しい行に追加します。

次に同じ月の経費を申請したときは、記録されたリンクから保存先を確認できます。

フォルダを作る処理と、次回使うための記録を残す処理を組み合わせた点が、今回のポイントです。

⑤ 判断できない場合は、処理を止める

登録済みのリンクが間違っている場合や、保存先を開けない場合は、代わりのフォルダを自動で作らず、エラーとして知らせます。同じ年月の行や、同じ名前のフォルダが複数あって保存先を決められない場合も同様です。

「まだ用意していない状態」と「登録内容に問題がある状態」を分けることで、意図しない場所への保存を防ぐようにしました。

以下は仕組みを紹介するための簡略例です。運用コードの差し替え用ではありません。拡張サービス「Drive API」を有効にし、読み書きできる例示用シートと親フォルダIDを用意する前提です。

購入日から年月とフォルダ名を作る

購入日を確認し、年と月を取り出してフォルダ名を組み立てます。例として「2026-08-31」を渡すと「2026年08月」になります。

function receiptMonthExample(purchaseDate) {
  const date = new Date(purchaseDate);
  if (!/^\d{4}-\d{2}-\d{2}$/.test(purchaseDate) ||
      !Number.isFinite(date.getTime()) ||
      date.toISOString().slice(0, 10) !== purchaseDate) {
    throw new Error('購入日を確認してください。');
  }
  const year = date.getUTCFullYear();
  const month = date.getUTCMonth() + 1;
  const name = year + '年' + String(month).padStart(2, '0') + '月';
  return { year: year, month: month, name: name };
}

管理表を確認して保存先を用意する

登録済みリンクがあれば、そのフォルダを確認して使います。リンクがない場合は、親フォルダ内を探し、同名フォルダがなければ作成します。最後に管理表へURLを残します。

この例では管理表の1行目を見出し、2行目以降を「年・月・フォルダURL」の順としています。運用シートとは配置を変えています。

// sheet: 年・月・フォルダURLの見出しが1行目にある例示用シート。
// parentId: 設定から取得済みの親フォルダID。
function prepareMonthFolderExample(sheet, parentId, purchaseDate) {
  const target = receiptMonthExample(purchaseDate);
  const count = Math.max(0, sheet.getLastRow() - 1);
  const rows = count ? sheet.getRange(2, 1, count, 3).getValues() : [];
  const matches = rows.map(function(values, i) {
    return { year: Number(values[0]), month: Number(values[1]),
      url: String(values[2]).trim(), row: i + 2 };
  }).filter(function(row) {
    return row.year === target.year && row.month === target.month;
  });
  if (matches.length > 1) throw new Error('管理表の年月が重複しています。');
  const existing = matches[0];
  if (existing && existing.url) {
    const match = existing.url.match(
      /^https:\/\/drive\.google\.com\/drive\/folders\/([\w-]+)(?:[?#].*)?$/
    );
    if (!match) throw new Error('保存先リンクを確認してください。');
    const folder = Drive.Files.get(match[1], {
      supportsAllDrives: true, fields: 'id,mimeType,trashed'
    });
    if (folder.trashed || folder.mimeType !== 'application/vnd.google-apps.folder') {
      throw new Error('登録された保存先を利用できません。');
    }
    return folder.id;
  }

  // parentIdは設定から得たGoogle DriveのIDを使用します。
  const result = Drive.Files.list({
    q: "'" + parentId + "' in parents and name = '" + target.name +
      "' and mimeType = 'application/vnd.google-apps.folder' and trashed = false",
    supportsAllDrives: true, includeItemsFromAllDrives: true,
    fields: 'files(id),nextPageToken,incompleteSearch', pageSize: 2
  });
  const folders = result.files || [];
  if (folders.length > 1 || result.nextPageToken || result.incompleteSearch) {
    throw new Error('保存先を一つに決められません。');
  }
  const folder = folders[0] || Drive.Files.create({
    name: target.name, mimeType: 'application/vnd.google-apps.folder',
    parents: [parentId]
  }, null, { supportsAllDrives: true, fields: 'id' });
  const url = 'https://drive.google.com/drive/folders/' + folder.id;
  if (existing) sheet.getRange(existing.row, 3).setValue(url);
  else sheet.appendRow([target.year, target.month, url]);
  return folder.id;
}

Drive.Files.list()で保存先を探し、Drive.Files.create()で不足するフォルダを作ります。検索結果を一つに決められないときは、新規作成せずに止めています。

運用実装にある同時申請のロック、作成途中のIDの記録、失敗後の復旧処理、設定シートの構成確認は、この例では省略しています。単独実行で流れを説明するためのコードです。

メモ・反省・次回やりたいこと

今回の修正では、画像を保存する処理だけでなく、その前に必要な保存先の準備も自動化しました。

一方で、何でも新しく作ればよいわけではありません。登録済みのリンクを優先し、同名フォルダの有無を確認し、判断できない場合は止めることで、管理する人が保存先を追えるようにしています。

次回は、申請が終わったあとに確認メールを送る仕組みを紹介します。

GASでスプレッドシートの同じ値が続くセル間の横罫線を自動で消す

投稿日：2026-10-07 | カテゴリ：技術 | GAS ツール 業務効率化 スプレッドシート

シフト表で同じ人が連続して入っているとき、セルの間の横罫線を消すと、ひとまとまりとして見やすくなります。

これまでは手作業で消していましたが、シフトを変更するたびに罫線も直すのが面倒だったので、GASで整えるようにしました。

今回は、上下のセルを比べて、同じ値が続くところだけ横罫線を消すツールの記録です。

このブログは、Google Apps Script（GAS）を使った自作ツールの記録や、開発の過程での気づきをまとめたものです。
丁寧な解説というより、「こんなこともGASでできるんだ」というアイディアのきっかけになれば幸いです。

やりたかったこと

シフト表を作っていると、同じ人の名前が縦に続くことがあります。例えば、山田さんが3枠続き、そのあと佐藤さんが2枠続くような場合です。

すべてのセルに横罫線があるより、同じ名前の間だけ線を消した方が、「ここからここまでは同じ人」と見やすくなります。

これまでは、シフト表を作ったあとに該当する罫線を手作業で消していました。人数や行数が多いと地味に時間がかかりますし、途中でシフトを変更すると、消した線を戻したり、別の線を消したりする必要がありました。

名前を直すたびに見た目まで修正するのが面倒だったので、入力した内容に合わせて罫線を整えられるようにしたいと思いました。

どんな動きにしたか

対象のシート名とセル範囲を指定し、その範囲内で上下のセルを比較します。

実行前と実行後を並べると、次のようになります。

列ごとに判定・空白同士はそのまま

同じ値が縦に続いている部分だけ、間の横罫線を消します。

判定は各列で独立しています。例えば4行目と5行目の間では、A列は「B／C」なので線を引き、B列は「E／E」なので線を消します。

値が違う場合や、片方だけ空白の場合には、黒い通常の1本線を引きます。両方とも空白の場合は、罫線を変更しません。図ではもともと線があるので、そのまま残っています。

対象範囲の上端・下端や縦罫線は変更しません。セルを結合するわけではなく、値はそれぞれのセルに入ったままです。

シフトを変更したあとにGASを実行すると、その時点の名前の並びに合わせて罫線を整えられます。

使ったロジック・ポイント

対象範囲を決め、値をまとめて取得する

getRange()は、処理するセルや範囲を取得するメソッドです。今回はA2:B9のように範囲を指定しています。

その範囲の値をgetValues()でまとめて取得し、現在のセルと1つ下のセルを比較します。比較するたびに値を読み直すのではなく、最初に取得した値を使う形です。

各列で上下のセルを比較する

行と列を順番に確認する「2重ループ」を使っています。

考え方は、「各行の各列について、1つ下の値と比べる」というものです。行全体が一致するかではなく、列ごとに判定するので、隣の列に引っ張られずに罫線を整えられます。

setBorder()で下側の罫線だけを変更する

今回の中心になるのが、セルの罫線を設定するsetBorder()です。

上下左右などを個別に変更できるので、今回は比較している上のセルの「下側の罫線」だけを操作しています。同じ値なら消し、違う値なら黒い通常線を引きます。

ほかの罫線には「変更しない」という指定のnullを使っています。表全体の罫線を作り直さず、必要な境界だけを変更するのがポイントです。

対象のスプレッドシートから「拡張機能」→「Apps Script」を開き、以下のコードを貼り付けます。

SHEET_NAMEを対象のシート名、RANGE_A1を名前が入っている範囲に変更して保存し、adjustBordersを実行してください。初回に権限の確認が表示された場合は、内容を確認して許可します。

              function adjustBorders() {
  // ===== 設定 =====
  const SHEET_NAME = '名前リスト'; // 対象シート名
  const RANGE_A1 = 'A2:B9';       // 対象範囲
  // ================

  const sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getSheetByName(SHEET_NAME);

  if (!sheet) {
    throw new Error(`シート「${SHEET_NAME}」が見つかりません。`);
  }

  const range = sheet.getRange(RANGE_A1);
  const values = range.getValues();

  const startRow = range.getRow();
  const startCol = range.getColumn();
  const numRows = range.getNumRows();
  const numCols = range.getNumColumns();

  // 各セルについて、1つ下のセルと比較
  for (let row = 0; row < numRows - 1; row++) {
    for (let col = 0; col < numCols; col++) {

      const currentValue = values[row][col];
      const nextValue = values[row + 1][col];

      // 空白同士は何もしない
      if (currentValue === '' && nextValue === '') {
        continue;
      }

      const cell = sheet.getRange(
        startRow + row,
        startCol + col
      );

      if (currentValue !== '' && currentValue === nextValue) {
        // 上下が同じ値 → 間の罫線を消す
        cell.setBorder(
          null, null, false, null, null, null
        );

      } else {
        // 上下が異なる → 黒の通常線を引く
        cell.setBorder(
          null, null, true, null, null, null,
          '#000000',
          SpreadsheetApp.BorderStyle.SOLID
        );
      }
    }
  }
}

名前は完全一致で比べています。「山田」と「山田 」のように余分なスペースがあると、違う値として扱われます。

また、消す対象は設定した罫線です。罫線を消しても、スプレッドシートの薄いグリッド線が表示されている場合があります。

実際に作って失敗したところ

最初は、「上下が同じ値なら罫線を消す」という条件だけで作っていました。

ところが、実際に使ってみると、空白セルが続く場所まで罫線が消えてしまいました。空白同士も「同じ値」と判定されていたためです。

シフト表には未入力の部分も多いので、そこまで線が消えると、意図していた見た目になりません。

そこで、同じ値かを判定する前に、「現在のセルと次のセルが両方空白なら何もしない」という条件を追加しました。

同じ値をまとめたいからといって、空白もまとめてよいとは限らないんですね。実際の表で試してみて、入力済みの名前と未入力のセルを分けて考える必要があると気づきました。

この条件は、空白部分の罫線を引き直す処理ではありません。すでに線が消えている場所も、その状態のままです。

使ってみてどう変わったか

シフトを変更したあと、上下の名前を見ながら罫線を1本ずつ直す代わりに、GASを実行して対象範囲を整えられるようになりました。

以前は同じ名前だった場所が別の名前に変われば、そこには横罫線を引き直します。消すだけでなく、変更後の内容に合わせて線を戻せるようにしたことで、修正時にも使える処理になりました。

大きな機能ではありませんが、データの変更に合わせて繰り返す小さな手作業を減らせるのが便利なところです。

次回やりたいこと

名前ごとに色を決めて、セルの背景色も一緒に整えられると面白そうです。

例えば、山田さんは薄い青、佐藤さんは薄い緑、鈴木さんは薄い黄色、といった形です。

背景色の調整も追加できれば、シフトを変更したあとにGASを実行することで、同じ名前の間の罫線と、名前ごとの色をまとめて整えられそうです。

今回は罫線だけにしましたが、次の機会に色の設定も作ってみるのはいいかもしれません。

まとめ

今回は、シフト表で同じ名前が縦に続く部分の横罫線を、GASで整えるようにしました。

上下の値を比べて罫線を変更するだけですが、空白をどう扱うかも、実際の用途では大事なポイントでした。

シフト表に限らず、担当者一覧や予定表など、同じ値のまとまりを見やすくしたい表にも応用できそうです。「毎回ちょっと面倒だな」と感じる見た目の調整も、GASで減らせる作業のひとつでした。
